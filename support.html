Common Issues & Solutions

❌ "You don't have access to this app"
Solution: This happens when the development version is installed. Ask your Jira admin to install the production version from the Atlassian Marketplace.
❌ Panel not showing in issue view
Solution: Click the gear icon ⚙️ at the top of the issue and select "Rich Content Editor" from the dropdown menu.
❌ "Content OK" but description still shows HTML
Solution: Hard refresh the page with Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows). The fix may have already been applied.
❌ Fix button not working
Solution: Ensure you have edit permissions on the issue. The app respects Jira's permission model — only users with edit access can fix descriptions.
❌ App shows loading spinner but doesn't load
Solution: Try refreshing the page. If the issue persists, contact support with the issue key and your Jira site URL.
