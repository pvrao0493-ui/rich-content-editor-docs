Privacy Policy

Last updated: May 12, 2026

🔒 Rich Content Editor does NOT collect, store, or share any personal data. All processing happens within your Atlassian instance.

1. Overview

Rich Content Editor ("the App") is a Jira Cloud app built on the Atlassian Forge platform. This Privacy Policy explains how the App handles data when installed on your Atlassian instance.

2. Data We Access

The App accesses the following data solely to provide its functionality:

  • Issue descriptions — To detect and fix raw HTML formatting issues
  • Issue summaries — To display the issue title in the panel
  • User identity — To verify the user is authenticated (via Atlassian)

3. Data We Do NOT Collect

  • We do NOT store any issue data outside your Atlassian instance
  • We do NOT collect personal information (name, email, phone)
  • We do NOT use cookies or tracking technologies
  • We do NOT share data with third parties
  • We do NOT send data to external servers
  • We do NOT log user activity

4. How Data Is Processed

All data processing occurs entirely within the Atlassian Forge platform:

  • The App reads issue description content via Jira REST API
  • HTML detection and conversion happens within Forge's secure runtime
  • Fixed content is written back to your Jira instance via Jira REST API
  • No data leaves the Atlassian infrastructure

5. Atlassian Forge Platform

This App is built on Atlassian Forge, which means:

  • All code runs within Atlassian's secure cloud infrastructure
  • Data is processed according to Atlassian's security standards
  • The App complies with Atlassian's security requirements

For more information about Atlassian's data practices, visit: Atlassian Privacy Policy

6. Permissions Required

The App requires the following Jira permissions:

  • read:jira-work — To read issue descriptions for HTML detection
  • write:jira-work — To update issue descriptions when user clicks "Fix"
  • read:jira-user — To verify user authentication

7. Data Retention

The App does not retain any data. Each interaction is stateless — no data is stored between sessions.

8. Security

The App follows security best practices:

  • Built on Atlassian Forge — a security-reviewed platform
  • No external network calls
  • No data persistence outside Jira
  • Changes only made when user explicitly clicks "Fix Description Now"

9. Children's Privacy

The App is designed for business use and is not directed at children under 13 years of age.

10. Changes to This Policy

We may update this Privacy Policy from time to time. We will notify users of any significant changes by updating the "Last updated" date at the top of this policy.
