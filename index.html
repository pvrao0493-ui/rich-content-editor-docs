What It Does

HTML Content Fixer identifies and repairs malformed HTML in your Jira issue descriptions. It removes deprecated tags, fixes broken elements, and ensures your content displays properly.

Common Issues It Fixes

  • Malformed or broken HTML tags (<div> without closing </div>)
  • Deprecated HTML elements (outdated formatting)
  • Inline styles and unnecessary attributes
  • Special character encoding issues
  • Nested tag validation errors
  • Whitespace and formatting inconsistencies

How to Use

1

Open any Jira Issue

Navigate to an issue that may have HTML formatting issues.

2

Open the App

Click the gear icon ⚙️ and select "HTML Content Fixer" from the apps menu.

3

Check Status

The app shows "Content OK" or "HTML Issues Detected".

4

Fix

Click "Fix Description Now" to automatically clean the HTML.

5

Done

Changes are saved instantly. Your description is now clean!

Permissions Required

The app requires these permissions:

  • read:jira-work — To read issue descriptions and detect HTML issues
  • write:jira-work — To update descriptions when you click "Fix"
  • read:jira-user — To verify user authentication

Frequently Asked Questions

Will the app modify issues automatically?

No. The app only makes changes when you explicitly click the "Fix Description Now" button.

Is my data safe?

Yes. The app is built on Atlassian Forge and all processing happens within Atlassian's secure infrastructure. No data is stored outside your instance.

Which issue types does it work with?

The app works with all Jira Cloud issue types - Bugs, Stories, Tasks, Epics, and custom types.

Can I undo a fix?

Yes. All changes appear in Jira's issue history. You can restore previous versions if needed.

Does it work with bulk operations?

Yes. v2.3.0 supports processing multiple issues through Jira filters.

Who can use the Fix button?

Any user with edit permissions on the issue can use the Fix button.
