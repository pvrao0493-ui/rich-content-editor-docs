The Problem It Solves

When migrating from Jira Data Center to Cloud, issue descriptions often contain raw HTML tags that display as plain text instead of formatted content.

❌ Before (Broken)

<p dir="auto">Operation Logs</p> <p dir="auto">VU logs</p> <b>Bold text</b> <br>Line break

✅ After (Fixed)

Operation Logs VU logs Bold text Line break

How to Use

1

Open any Jira Issue

Navigate to any Jira issue that may have HTML formatting issues in the description.

2

Click the Gear Icon ⚙️

Click the gear/apps icon at the top of the issue to see installed apps.

3

Select "Rich Content Editor"

Click on "Rich Content Editor" from the apps dropdown menu.

4

Check the Status Badge

The panel shows either "Content OK" (no issues) or "HTML Issue Detected" (needs fixing).

5

Click "Fix Description Now"

If HTML issues are detected, click the Fix button to automatically convert HTML to proper formatting.

Required Permissions

The app requires the following Jira permissions to function:

Permission Purpose
read:jira-work Read issue descriptions to detect HTML formatting issues
write:jira-work Update issue descriptions when user clicks "Fix Description Now"
read:jira-user Verify user authentication within the Atlassian platform

Frequently Asked Questions

Will the app modify my issues automatically?

No. The app only reads issue data when you open the panel. Changes are only made when you explicitly click the "Fix Description Now" button.

Is my data safe?

Yes. The app is built on Atlassian Forge and all processing happens within Atlassian's secure infrastructure. No data is stored or sent outside your Atlassian instance.

Which issue types does it work with?

The app works with all Jira Cloud issue types — Bugs, Stories, Tasks, Epics, Sub-tasks, and custom issue types.

Can I undo the fix?

Yes. All changes are tracked in Jira's issue history. You can view previous versions and restore them using Jira's built-in version history.

Does it work with all Jira Cloud projects?

Yes. The app works with all Jira Cloud project types — Scrum, Kanban, and Business projects.

Who can use the Fix button?

Any user with edit permissions on the issue can use the Fix button. The app respects Jira's existing permission model.
